# ✨ Case Mood · Micrositio Showroom Oficial

Showroom digital interactivo de **Case Mood** para exhibir las colecciones de fundas de celular, con animaciones fluidas, carrusel crossfade automático, vista Lightbox HD y conversión directa a la tienda online oficial y WhatsApp.

---

## 🚀 Características Principales

1. **Gestión desde el Admin de Case Mood**:
   - En el panel admin de tu tienda (`casemood.pages.dev/admin`) en la pestaña **"✨ Micrositio Showroom"**, podés elegir qué modelos exponer, asignarles títulos y frases personalizadas, y marcarlos como destacados.
   - El showroom se sincroniza en vivo con tu tienda.
2. **Carrusel Automático con Crossfade**:
   - Cada tarjeta rota suavemente entre los ángulos y fotos de Cloudinary cada 3.5 segundos con pausa al pasar el cursor o apoyar el dedo.
3. **Modal Lightbox HD**:
   - Pantalla completa con selector de modelos, gestos táctiles (swipe), botón **"Comprar en Tienda Oficial"** y **"Consultar por WhatsApp"**.
4. **Hero con Mascotas Animadas**:
   - Los dos personajes ilustrados (Mascota Cool 😎 con anteojos y Mascota Cute 🌸 con flor) con animaciones CSS flotantes.
5. **Filtros Avanzados**:
   - Por colección (pills), por modelo de celular (iPhone, Samsung) y buscador en tiempo real.
6. **Barra Flotante Mobile**:
   - Accesos directos a Instagram (`@casemood__`), WhatsApp y Tienda Oficial.

---

## 🛠️ Stack Tecnológico

- **Framework**: Next.js (App Router) + TypeScript
- **Estilos**: Tailwind CSS
- **Iconografía**: Lucide React + Custom Instagram SVG
- **Despliegue**: Listo para Vercel o Cloudflare Pages
